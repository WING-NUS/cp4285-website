# Week 07 delivery timeline

| Segment | Time | Delivery cue |
| --- | ---: | --- |
| In-class mastery quiz | 30 min | Students complete the invigilated Canvas Quiz, screen-record their primary test-taking device, use only pre-prepared notes, and submit both quiz and recording before the project critique. |
| Break and recording check | 5 min | Students confirm that their screen recording is saved or uploaded to Canvas by 12:00 noon; run the shared five-minute timer. |
| Announcements and Essay 2 briefing | 3 min | Introduce the 20–30 minute iPython / Jupyter notebook exercise; future-week choices should use the Schedule description to synthesize an appropriate tutorial or programming task. |
| Project design review | 35 min | Teams present their application domain, dataset, user problem, objective, baselines, evaluation plan, and ethical risks; peers identify a concrete revision. |
| Ethics and feasibility synthesis | 10 min | Surface one scope, bias, or stakeholder risk that could alter a project decision. |
| Summary, pre-lecture exercise, and Week 08 bridge | 5 min | Close with the summary, introduce the Canvas ordering-and-peer-reply task, then use the full-bleed teal preview to connect defensible project designs to learning-to-rank and ranked user experience. |

## Activity record

- **Project design review:** task = use the assigned presentation, methodology, or administration lens to diagnose a peer team's project update; expected output = one specific, constructive, actionable Canvas comment; instructor synthesis = connect feedback to a testable next step.
- **Week 08 pre-lecture exercise:** task = choose five items from a recommendation domain and order them for immediate fit and semester discovery, then critique one peer order through a named card-suit treatment lens; expected output = two lists, one explained trade-off, and one 50–70 word peer reply; instructor synthesis = different ranking purposes make different errors matter.
